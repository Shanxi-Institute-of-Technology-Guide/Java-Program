# Java Programming Exercises

A set of introductory Java programs demonstrating console I/O, objects, numerical calculation, sorting, and recursion.

> Academic context: this directory contains course lab or coursework solutions.

## Topics

- Account objects and account demonstrations
- BMI calculation
- Bubble sort
- Fibonacci numbers

## Compile and Run

```powershell
javac -d out *.java
java -cp out Main
```

Replace `Main` with the class that contains the exercise you want to run. A JDK is required.
